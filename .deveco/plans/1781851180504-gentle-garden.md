# 玻璃拟态科技风 UI 大改造 + 功能修补 (浅色/深色双模式)

## Goal

将 family_food_app 视觉风格升级为"**玻璃拟态科技风**"——**浅色模式用柔和毛玻璃+品牌绿渐变发光**，**深色模式用深色毛玻璃+霓虹发光**，双模式都时尚漂亮。同时修补3个功能缺陷。

**核心原则：浅色模式是主要使用场景，必须同样好看。**

## Scope / Non-goals

**包含:** 双模式设计系统升级、6核心页重设计、5新组件、全站视觉统一、3功能bug修补

**不包含:** 数据层重构、真正On-Device LLM、国际化/无障碍扩展、新业务功能

## Current State And Constraints

### 视觉审计7大问题
1. 49页面统一绿色渐变头 → 像一个页面重复49次
2. Emoji当图标 → 跨设备不一致，无法品牌化
3. 扁平阴影(4%透明度) → 无层次感
4. 6核心页零动画 → 无入场/数值/按压动画
5. Stock DataPanel到处重复 → 无特色
6. 最大字号28px → 英雄数值不突出
7. 无插画无装饰 → EmptyState只有emoji

### 功能审计3大问题
1. E2E加密Feed写后不解密，密钥仅存内存
2. On-Device LLM硬编码false
3. 食谱社区无预置数据

### ArkTS可用API(已验证)
- `backgroundBlurStyle(BlurStyle.X, {color,adaptiveColor,scale})` — 核心毛玻璃API，当前零使用
- `backdropBlur(number)` — 仅用一次
- `linearGradient` on Text — 可用但零使用
- 彩色shadow — 可用但零使用
- `Circle`+`startAngle`/`sweepAngle` — 已验证
- `animateTo`/`TransitionEffect` — 基础设施完备
- `adaptiveColor: AdaptiveColor.DEFAULT` — **关键：backgroundBlurStyle的adaptiveColor参数可自动适配浅色/深色模式的模糊背景色**

## Design — 双模式玻璃拟态视觉语言

### 浅色模式 (主要场景)

| 元素 | 当前 | 目标 |
|------|------|------|
| **背景** | 扁平`#F2F7F2` | 渐变`#E8F5E9→#F1F8E9→#F5FFF5` + 微妙绿色光斑 |
| **卡片** | 白色+微弱黑影 | 毛玻璃`rgba(255,255,255,0.72)`+`backgroundBlurStyle(BlurStyle.Thin, {adaptiveColor:AdaptiveColor.DEFAULT})`+1px白边高光+柔和绿色发光shadow |
| **头部** | 统一绿色条 | 更丰富的3色渐变`#43A047→#66BB6A→#81C784`+底部雾化过渡 |
| **强调色** | 扁平`#43A047` | 渐变绿`#43A047→#66BB6A`+柔和绿色发光`shadow({radius:8, color:'#2243A047'})` |
| **文字** | 深色文字+浅色背景 | 深色文字+渐变高亮文字(品牌绿渐变) |
| **阴影** | 黑色4-10% | 强化黑影20%+绿色柔和发光 |
| **仪表** | 4个DataPanel | 渐变弧线+数字动画+柔和发光 |
| **按钮** | 扁平绿矩形 | 渐变绿背景+柔和发光+按压缩放 |

### 深色模式

| 元素 | 目标 |
|------|------|
| **背景** | 深色渐变`#0D1B0E→#1A2F1C→#0A1A0D`+霓虹光斑 |
| **卡片** | 深色毛玻璃`rgba(255,255,255,0.08)`+`backgroundBlurStyle(BlurStyle.Thick)`+霓虹绿发光 |
| **头部** | 深色沉浸渐变+霓虹绿文字 |
| **强调色** | 霓虹绿`#69F0AE`发光+品牌绿`#00E676` |
| **阴影** | 彩色发光15-40% |

### 关键：`adaptiveColor` 实现双模式自适应

```typescript
// GlassCard核心 — adaptiveColor自动适配浅色/深色
.backgroundBlurStyle(BlurStyle.Thin, {
  adaptiveColor: AdaptiveColor.DEFAULT,  // 浅色模式白底模糊，深色模式暗底模糊
  scale: 1.0
})
```

这使得**单个GlassCard组件在双模式下自动呈现不同风格**，无需if/else判断ThemeMode。

### TC()函数升级策略

修改TC()函数，根据ThemeMode返回不同令牌：
- `TC('BG_PAGE')` → 浅色返回`#F2F7F2`，深色返回`#0D1B0E`
- `TC('CARD_BG')` → 浅色返回`GLASS_BG_LIGHT`，深色返回`GLASS_BG_DARK`
- `TC('GLOW_SHADOW')` → 浅色返回`GLOW_GREEN_SOFT`，深色返回`GLOW_NEON_GREEN`
- 所有新令牌都通过TC()获取，自动适配模式

## Risks And Compatibility

- **backgroundBlurStyle性能**: 低端设备可能卡顿;方案:GlassCard提供`enableBlur`参数,低端设备fallback为纯色背景
- **adaptiveColor兼容性**: 需确认SDK 6.1支持`AdaptiveColor.DEFAULT`(API 11+)
- **Circle弧线渐变stroke**: ArkUI Circle.stroke不支持linearGradient;方案:用Canvas分段绘制或用多个短弧Circle拼合+不同颜色
- **现有浅色模式不破坏**: 所有新增令牌通过TC()函数获取,浅色模式返回值与现有令牌兼容;旧代码不引用新令牌则不受影响

## Rollback

- 所有视觉修改通过TC()函数控制,回滚只需恢复TC()返回旧令牌
- AppTheme新增令牌不删旧令牌
- 新组件(GlassCard/GradientArc等)独立文件,删除即回滚
- 功能修补(D1-D3)独立于视觉,可单独回滚
