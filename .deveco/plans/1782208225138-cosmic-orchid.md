# 食安助手 UI 3.0 — "暖食光" 设计方案

## 用户确认
- ✅ 图标：先试SymbolGlyph，失败自动回退emoji
- ✅ 配色：陶土+鼠尾草+蜜金 三色协奏

## 配色系统

| 角色 | 色名 | 色值 | 用途 |
|------|------|------|------|
| 主色 | 暖陶土 | `#E07856` | header、主按钮、品牌色 |
| 辅色 | 鼠尾草 | `#7CB342` | 健康/正面数据、营养进度条 |
| 强调 | 蜜金 | `#F5A623` | 扫描CTA、提示 |
| 底色 | 暖白 | `#FBF9F6` | 页面背景 |
| 卡片 | 纯白 | `#FFFFFF` | 卡片表面 |
| 文字 | `#2D2A26` → `#707070` → `#B0B0B0` | 标题→正文→注释 |

## 鸿蒙6.1特性运用

| 特性 | 用法 |
|------|------|
| SymbolGlyph | 启用42个原生图标+SCALE按压动画 |
| backgroundBlurStyle | TabBar底栏毛玻璃 |
| animateTo | 卡片入场+弧形进度+数字动画 |
| TransitionEffect | section淡入上滑 |

## 实施步骤

### 1. DesignTokens 三色系统
更新 `DesignTokens.ets` — 陶土/鼠尾草/蜜金三色+暖白底

- 暖底色贴士条
- 白卡工具列表（DSListRow + SymbolGlyph）
- 白卡成员列表（陶土渐变头像）

### 4. ProfilePage 重写
- 陶土渐变header + 头像 + 统计行

### 5. AiChatPage 优化

### 6. ScanPage + MainTabsPage
